# Prompt Starters

## The formula
**Goal** (what done looks like) + **Inputs** (where to look) + **Rules** (what to avoid) + **Output** (file name and format)

---

## Get oriented
```
Read BRIEF.md and everything in [folder]. Summarize what's here and what
you'd suggest doing first. Don't change anything yet.
```

## Organize files
```
Organize [folder] into subfolders by [topic / date / type]. Rename files
so the names are clear. Show me the plan as a table before moving anything.
```

## Summarize many documents
```
Read every file in [folder] and create [summary.md] with the key points,
decisions, and open questions. Note which file each point came from.
```

## Pull out action items
```
From the notes in [folder], list every task with the owner and due date
in [action-items.md]. Flag conflicts or anything without an owner.
```

## Clean up a spreadsheet
```
Clean up [file.csv]: fix inconsistent formatting, flag duplicates and
blanks, and save it as [file-cleaned.csv]. Keep the original. Tell me
what you changed.
```

## Compare two versions
```
Compare [file-A] and [file-B]. List what was added, removed, or changed
in plain language. Save it as [changes.md].
```

## Draft something from your material
```
Using [files/folder], draft a [one-page update / email / proposal] for
[audience]. Keep it [tone/length]. Save it as [file name].
```

## Check the work
```
Review [file] against BRIEF.md. What's missing, wrong, or unclear?
Show your work for any numbers.
```

## Keep going
```
Good. Now [next step]. Same rules as before.
```

## Undo
```
That's not what I wanted. Undo your last change and put things back how
they were. Then [clearer instruction].
```
